I personally use Zen, a modern web browser that allows more customization than Google Chrome or Firefox. You can use whichever browser you like, but this is a guide for anyone who wants to have Zen with my customization.

# Installing Zen:

Go to this website https://zen-browser.app/download/ and download Zen. You must leave everything default unless you know what you're actually doing. [ I RECOMMEND SELECTING STANDARD INSTALLATION ]

If you plan to use this browser for a long time, make it your default browser.

# Zen Customization:

Once you are on this screen, click on the three dots in the top-right corner and go to Settings. In Settings, go to the "Zen Mods" section and click on the "Import Mods" button. Download and import this file [ZenMods](https://github.com/GIT-Oxone/W11-Dotfiles/blob/main/Zen/ZenModsExport.json)

Now we're gonna set up a custom font. You can use whichever you like the most, the process is the same, but I'll be using [JetBrainsMono Nerd Font Mono](https://github.com/GIT-Oxone/W11-Dotfiles/blob/3aa7b8ebe60a936764a7c8fcc5e63ea3e1c6c110/Zen/JetBrainsMonoNerdFontMono-Regular.ttf). Just double-click in your File Explorer, install it on Windows, then go to Zen Mods tab, click on the gear icon of the "Custom uiFont" mod, and click "Custom". In Font Family, put this: **JetBrainsMono Nerd Font Mono**, and click OK. Now you should see your browser with a cooler aspect. 

Now we'll set up transparency and background colour. In "Zen Mods" tab, click the gear icon of the "Transparent Zen" mod, and copy this settings:

<img width="675" height="323" alt="{602D5C8F-7F5E-4570-BD30-3ACD3953BAB1}" src="https://github.com/user-attachments/assets/e3f1ffef-c961-42c8-a48c-e416b21c2a49" />

You shouldn't touch anything else unless you know what you're doing, or wanna experiment with the mods settings. It's up to you. 

To have those icons there as me, they're like bookmarks in Chrome. These are called "Essentials" in Zen. You can have up to 12. To do it, just open a YouTube page (for example), right click and click "Add to Essentials", now it should appear.
